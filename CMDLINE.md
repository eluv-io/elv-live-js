# EluvioLive CLI

The complete command reference for `elv-live`, `elv-admin`, and `elv-stream` is published at:

**<https://docs.eluv.io/tools/eluvio-live-cli/overview/>**

It includes every command with its arguments and options.

For the commands available in your installed version, run one of:

- `elv-live --help`
- `elv-stream --help`
- `elv-admin --help`

Or run `<tool> <command> --help` for a single command.
